WEB INVENTARIS BARANG

Deskripsi
Aplikasi untuk membantu pengelolaan peminjaman barang inventaris seperti misalnya proyektor, laptop,
kamera, alat laboratorium, peralatan organisasi, atau fasilitas kampus.aplikasi ini dibuat untuk untuk menunjang kemudahan dalam peminjaman barang

Latar Belakang
Pengelolaan barang inventaris dan pencatatan peminjaman dapat dilakukan secara manula akan tetapi user akan kesulitan
mengelola data barang serta kesulitan mengetahui barang apa saja yang dipinjam,status peminjaman dan riwayat peminjaman menjadi tantangan dalam peminjaman offline

Tujuan 
1. Membuat sistem peminjaman online inventaris barang berbasis web 
2. Memudahkan dalam pengelolaan data kategori barang
3. Memudahkan dalam mengetahui barang masuk dan keluar
4. Mengetahui status barang peminjaman dan riwayat barang peminjaman
5. membuat data peminjaman lebih efisien dan terstruktur

Target Pengguna
- Admin
- Admin CS
- Peminjam
- Petugas

Fitur Utama
- Login dan Log out
- Dashboard
- Session dan Proteksi halaman
- Pengelolaan data barang
- Pengelolaan data peminjaman
- Status Peminjaman
- Tambah data
- Edit data
- Memakai id setiap barang
- Memberi batas waktu 3 hari peminjaman
- Memberi history peminjaman
  

Data Utana
1. Users
2. Kaategori barang
3. Jenis barang
4. Barang
5. Peminjaman

Teknologi 
- HTML5 untuk struktur halaman
- CSS3 untuk tampilan dan responsivitas
- JavaScript untuk tanggal/waktu, validasi ringan, atau interaksi antarmuka
- PHP native untuk logika aplikasi
- MySQL atau MariaDB untuk penyimpanan data
- jQuery dan AJAX untuk pagination data
- Git dan GitHub/GitLab untuk version control
- Hosting untuk publikasi aplikasi akhir
